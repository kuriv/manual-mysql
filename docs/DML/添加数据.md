# 添加数据

执行下面的 SQL 语句，向指定表中的部分字段添加数据。

```sql
INSERT INTO user_login (id, username, password, create_time)
VALUES (1, 'Tom', '123456', '2000-01-01 00:00:00');
```

执行下面的 SQL 语句，向指定表中的全部字段添加数据。

```sql
INSERT INTO user_login
VALUES (null, 'Jerry', '654321', CURRENT_TIMESTAMP);
```

执行下面的 SQL 语句，批量添加数据。

```sql
INSERT INTO user_login (id, username, password, create_time)
VALUES (3, 'Spike', '123456', '2000-01-01 00:00:00'),
       (4, 'Tyke', '123456', '2000-01-01 00:00:00');

INSERT INTO user_login
VALUES (null, 'Butch', '654321', CURRENT_TIMESTAMP),
       (null, 'Tuffy', '654321', CURRENT_TIMESTAMP);
```
