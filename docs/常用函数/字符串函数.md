# 字符串函数

执行下面的 SQL 语句，将多个字段或字符串拼接成一个完整字符串。

```sql
SELECT CONCAT('ID: ', id, ', username: ', username) FROM user_login;
```

执行下面的 SQL 语句，将字符串全部转为小写字母。

```sql
SELECT username, LOWER(username) AS lower_username FROM user_login;
```

执行下面的 SQL 语句，将字符串全部转为大写字母。

```sql
SELECT username, UPPER(username) AS upper_username FROM user_login;
```

执行下面的 SQL 语句，在字符串左侧填充指定字符。

```sql
SELECT id, LPAD(id, 5, '0') AS format_id FROM user_login;
```

执行下面的 SQL 语句，在字符串右侧填充指定字符。

```sql
SELECT username, RPAD(username, 8, '*') AS masked_username FROM user_login;
```

执行下面的 SQL 语句，去掉字符串首尾的空格。

```sql
SELECT username, TRIM(username) AS clean_username FROM user_login;
```

执行下面的 SQL 语句，从字符串中截取指定位置、指定长度的内容。

```sql
SELECT username, SUBSTRING(username, 1, 3) AS short_name FROM user_login;
```
