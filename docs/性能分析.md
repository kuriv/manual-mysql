# 性能分析

执行下面的 SQL 语句，查看所有当前连接会话。

```sql
SHOW FULL PROCESSLIST;
```

执行下面的 SQL 语句，查看所有 SQL 语句的执行状态。

```sql
SHOW GLOBAL STATUS LIKE 'Com_%';
```

执行下面的 SQL 语句，查看所有 SELECT 语句的执行次数。

```sql
SHOW GLOBAL STATUS LIKE 'Com_select';
```

执行下面的 SQL 语句，查看所有 INSERT 语句的执行次数。

```sql
SHOW GLOBAL STATUS LIKE 'Com_insert';
```

执行下面的 SQL 语句，查看所有 UPDATE 语句的执行次数。

```sql
SHOW GLOBAL STATUS LIKE 'Com_update';
```

执行下面的 SQL 语句，查看所有 DELETE 语句的执行次数。

```sql
SHOW GLOBAL STATUS LIKE 'Com_delete';
```

执行下面的 SQL 语句，查看所有事务的提交次数。

```sql
SHOW GLOBAL STATUS LIKE 'Com_commit';
```

执行下面的 SQL 语句，查看所有事务的回滚次数。

```sql
SHOW GLOBAL STATUS LIKE 'Com_rollback';
```

执行下面的 SQL 语句，查看慢查询日志开启状态。

```sql
SELECT @@global.slow_query_log;
```

执行下面的 SQL 语句，开启慢查询日志。注意，慢查询日志默认为关闭，可以在配置文件中进行设置。

```sql
SET @@global.slow_query_log = 1;
```

执行下面的 SQL 语句，查看慢查询时间阈值。

```sql
SELECT @@global.long_query_time;
```

执行下面的 SQL 语句，设置慢查询时间阈值。

```sql
SET @@global.long_query_time = 2;
```

执行下面的 SQL 语句，查看慢查询日志文件路径。

```sql
SELECT @@global.slow_query_log_file;
```

执行下面的 SQL 语句，修改慢查询日志文件路径。

```sql
SET @@global.slow_query_log_file = '/var/lib/mysql/mysql-slow.log';
```

执行下面的 SQL 语句，查看历史执行的 SQL 语句以及真实执行耗时。

```sql
SELECT SQL_TEXT, TIMER_WAIT / 1000000000 AS TIME
FROM performance_schema.events_statements_history
WHERE TIMER_WAIT > 2000000000
ORDER BY TIMER_WAIT DESC;
```

执行下面的 SQL 语句，通过 MySQL 优化器分析预估的执行计划。

```sql
EXPLAIN SELECT * FROM user;
```
