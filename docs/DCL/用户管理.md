# 用户管理

执行下面的 SQL 语句，查询 MySQL 数据库服务中所有的用户。

```sql
SELECT * FROM user;
```

执行下面的 SQL 语句，创建本地用户，仅在 MySQL 数据库服务本机登录。

```sql
CREATE USER 'demo'@'localhost' IDENTIFIED BY '123456';
```

执行下面的 SQL 语句，创建可任意 IP 远程连接的用户。

```sql
CREATE USER 'demo'@'%' IDENTIFIED BY '123456';
```

执行下面的 SQL 语句，创建仅允许指定 IP 远程连接的用户。

```sql
CREATE USER 'demo'@'192.168.1.233' IDENTIFIED BY '123456';
```

执行下面的 SQL 语句，修改指定用户的密码。

```sql
ALTER USER 'demo'@'localhost' IDENTIFIED BY '654321';
```

执行下面的 SQL 语句，删除指定用户。

```sql
DROP USER 'demo'@'localhost';
```
