# 权限控制

执行下面的 SQL 语句，查询指定用户的权限。

```sql
SHOW GRANTS FOR 'demo'@'localhost';
```

执行下面的 SQL 语句，为指定用户授予全局最高权限。

```sql
GRANT ALL PRIVILEGES ON *.* TO 'demo'@'localhost';
```

执行下面的 SQL 语句，为指定用户授予指定数据库的完整权限。

```sql
GRANT ALL PRIVILEGES ON demo.* TO 'demo'@'localhost';
```

执行下面的 SQL 语句，为指定用户授予指定数据库的只读权限。

```sql
GRANT SELECT ON demo.* TO 'demo'@'localhost';
```

执行下面的 SQL 语句，为指定用户授予指定数据库的基础读写权限。

```sql
GRANT SELECT, INSERT, UPDATE, DELETE ON demo.* TO 'demo'@'localhost';
```

执行下面的 SQL 语句，仅允许指定用户操作指定表的部分字段。

```sql
GRANT SELECT(id, username, create_time) ON demo.user_login TO 'demo'@'localhost';
```

执行下面的 SQL 语句，为指定用户授予指定数据库的只读权限，并允许用户将自身权限转授其他用户。

```sql
GRANT SELECT ON demo.* TO 'demo'@'localhost' WITH GRANT OPTION;
```

执行下面的 SQL 语句，撤销指定用户的全局最高权限。

```sql
REVOKE ALL PRIVILEGES ON *.* FROM 'demo'@'localhost';
```

执行下面的 SQL 语句，撤销指定用户的部分权限。

```sql
REVOKE INSERT, UPDATE, DELETE ON demo.* FROM 'demo'@'localhost';
```

执行下面的 SQL 语句，单独撤销指定用户的转授权限。

```sql
REVOKE GRANT OPTION ON demo.* FROM 'demo'@'localhost';
```
