# 分组查询

执行下面的 SQL 语句，按指定字段对数据进行分组。

```sql
SELECT DATE(create_time) AS date, COUNT(id) AS total
FROM user_login
GROUP BY DATE(create_time);
```

执行下面的 SQL 语句，对分组聚合后的结果进行二次过滤。

```sql
SELECT DATE(create_time) AS date, COUNT(id) AS total
FROM user_login
GROUP BY DATE(create_time)
HAVING total > 1;
```
