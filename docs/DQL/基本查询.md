# 基本查询

执行下面的 SQL 语句，查询指定表中的所有数据。

```sql
SELECT * FROM user_login;
```

执行下面的 SQL 语句，查询指定表中的部分字段数据。

```sql
SELECT id, username, create_time FROM user_login;
```

执行下面的 SQL 语句，查询指定表中的部分字段数据，并使用别名。

```sql
SELECT id, username as name FROM user_login;
```

执行下面的 SQL 语句，将查询结果去重。

```sql
SELECT DISTINCT create_time from user_login;
```

执行下面的 SQL 语句，按主键精确查询。

```sql
SELECT * FROM user_login WHERE id = 1;
```

执行下面的 SQL 语句，按数值比较查询。

```sql
SELECT * FROM user_login WHERE id > 1;
```

执行下面的 SQL 语句，按数值范围查询。

```sql
SELECT * FROM user_login WHERE id BETWEEN 2 AND 4;
```

执行下面的 SQL 语句，按集合查询。

```sql
SELECT * FROM user_login WHERE username IN ('Tom', 'Jerry');
```

执行下面的 SQL 语句，将查询条件取反。

```sql
SELECT * FROM user_login WHERE NOT username = 'Tom';
```

执行下面的 SQL 语句，判断指定字段的值是否是 NULL 。

```sql
SELECT * FROM user_login WHERE create_time IS NULL;
```

执行下面的 SQL 语句，判断指定字段的值是否不是 NULL 。

```sql
SELECT * FROM user_login WHERE create_time IS NOT NULL;
```

执行下面的 SQL 语句，使用通配符进行模糊查询，匹配任意字符出现任意次数。

```sql
SELECT * FROM user_login WHERE username LIKE 'T%';
```

执行下面的 SQL 语句，使用通配符进行模糊查询，仅匹配单个字符。

```sql
SELECT * FROM user_login WHERE username LIKE '_om';
```

执行下面的 SQL 语句，使用多条件 OR 查询。

```sql
SELECT * FROM user_login WHERE id = 1 OR username = 'Tom';
```

执行下面的 SQL 语句，使用多条件 AND 查询。

```sql
SELECT * FROM user_login WHERE id > 1 AND username LIKE 'T%';
```
