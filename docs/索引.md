# 索引

执行下面的 SQL 语句，查看指定表的所有索引。

```sql
SHOW INDEX FROM user;
```

执行下面的 SQL 语句，为指定表的字段添加普通索引。

```sql
CREATE INDEX idx_name ON user (name);
```

执行下面的 SQL 语句，为指定表的字段添加唯一索引。

```sql
CREATE UNIQUE INDEX idx_name ON user (name);
```

执行下面的 SQL 语句，为指定表的字段添加联合索引。

```sql
CREATE INDEX idx_name_dept ON user (name, dept_id);
```

执行下面的 SQL 语句，为指定表的字段添加前缀索引。

```sql
CREATE INDEX idx_name_prefix ON user (name(2));
```

执行下面的 SQL 语句，删除指定表的索引。

```sql
DROP INDEX idx_name ON user;
```

执行下面的 SQL 语句，建议使用指定的索引。

```sql
SELECT * FROM user USE INDEX (idx_name) WHERE name = 'Tom';
```

执行下面的 SQL 语句，忽略指定的索引。

```sql
EXPLAIN SELECT * FROM user IGNORE INDEX (idx_name) WHERE name = 'Tom';
```

执行下面的 SQL 语句，强制使用指定的索引。

```sql
EXPLAIN SELECT * FROM user FORCE INDEX (idx_name) WHERE name = 'Tom';
```
