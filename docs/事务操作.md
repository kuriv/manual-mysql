# 事务操作

执行下面的 SQL 语句，查看事务提交方式。

```sql
SELECT @@autocommit;
```

执行下面的 SQL 语句，关闭事务自动提交模式。

```sql
SET autocommit = 1;
```

执行下面的 SQL 语句，查看事务隔离级别。

```sql
SELECT @@transaction_isolation;
```

执行下面的 SQL 语句，设置事务隔离级别。

```sql
SET transaction_isolation = 'REPEATABLE-READ';
```

执行下面的 SQL 语句，显式开启单次事务。

```sql
START TRANSACTION;
```

执行下面的 SQL 语句，提交事务。

```sql
COMMIT;
```

执行下面的 SQL 语句，回滚事务。

```sql
ROLLBACK;
```
