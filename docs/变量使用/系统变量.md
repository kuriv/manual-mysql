# 系统变量

执行下面的 SQL 语句，查看所有会话变量。

```sql
SHOW SESSION VARIABLES;
```

执行下面的 SQL 语句，查看所有全局变量。

```sql
SHOW GLOBAL VARIABLES;
```

执行下面的 SQL 语句，通过模糊匹配方式查找会话变量。

```sql
SHOW SESSION VARIABLES LIKE '%buffer%';
```

执行下面的 SQL 语句，通过模糊匹配方式查找全局变量。

```sql
SHOW GLOBAL VARIABLES LIKE '%buffer%';
```

执行下面的 SQL 语句，查看指定会话变量的值。

```sql
SELECT @@session.character_set_client;
```

执行下面的 SQL 语句，查看指定全局变量的值。

```sql
SELECT @@global.character_set_client;
```

执行下面的 SQL 语句，修改指定会话变量的值。

```sql
SET @@session.character_set_client = 'utf8mb4';
```

执行下面的 SQL 语句，修改指定全局变量的值。

```sql
SET @@global.character_set_client = 'utf8mb4';
```
