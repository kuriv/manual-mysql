# 主从复制

首先，修改主库的 `my.cnf` 配置文件内容如下。

```
# For advice on how to change settings please see
# http://dev.mysql.com/doc/refman/8.4/en/server-configuration-defaults.html

[mysqld]
server-id = 1
log-bin = mysql-bin
# binlog-ignore-db = mysql
# binlog-do-db = demo
```

随后，修改从库的 `my.cnf` 配置文件内容如下。

```
[mysqld]
server-id = 2
read_only = ON
```

执行下面的 SQL 语句，为主库创建用于主从复制操作的专用用户。

```sql
CREATE USER 'replication'@'%' IDENTIFIED BY 'replication';
GRANT REPLICATION SLAVE ON *.* TO 'replication'@'%';
FLUSH PRIVILEGES;
```

执行下面的 SQL 语句，查看主库二进制日志起始位置。

```sql
SHOW BINARY LOG STATUS;
```

执行下面的 SQL 语句，为从库配置主从复制参数。

```sql
CHANGE REPLICATION SOURCE TO
SOURCE_HOST = 'mysql-master',
SOURCE_PORT = 3306,
SOURCE_USER = 'replication',
SOURCE_PASSWORD = 'replication',
SOURCE_LOG_FILE = 'mysql-bin.000001',
SOURCE_LOG_POS = 1024,
GET_SOURCE_PUBLIC_KEY = 1;
```

执行下面的 SQL 语句，为从库开启主从复制。

```sql
START REPLICA;
```

执行下面的 SQL 语句，为从库关闭主从复制。

```sql
STOP REPLICA;
```

执行下面的 SQL 语句，在从库中验证主从复制状态。

```sql
SHOW REPLICA STATUS;
```
