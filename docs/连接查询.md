# 连接查询

执行下面的 SQL 语句，使用隐式内连接查询多张表数据。

```sql
SELECT o.id, u.name AS username, o.amount, d.name AS department
FROM user AS u,
     user_dept AS d,
     user_order AS o
WHERE u.dept_id = d.id AND u.id = o.user_id;
```

执行下面的 SQL 语句，使用显式内连接查询多张表数据。

```sql
SELECT o.id, u.name AS username, o.amount, d.name AS department
FROM user AS u
INNER JOIN user_dept AS d ON u.dept_id = d.id
INNER JOIN user_order AS o ON u.id = o.user_id;
```

执行下面的 SQL 语句，使用自连接查询多张表数据。

```sql
SELECT a.id, a.name, a.dept_id, b.id, b.name, b.dept_id
FROM user AS a
INNER JOIN user AS b ON a.id = b.id;
```

执行下面的 SQL 语句，使用左外连接查询多张表数据。

```sql
SELECT u.id, u.name AS username, d.name AS department
FROM user AS u
LEFT JOIN user_dept AS d ON u.dept_id = d.id;
```

执行下面的 SQL 语句，使用右外连接查询多张表数据。

```sql
SELECT u.id, u.name AS username, d.name AS department
FROM user AS u
RIGHT JOIN user_dept AS d on u.dept_id = d.id;
```
