# 子查询

执行下面的 SQL 语句，使用嵌套子查询。

```sql
SELECT *
FROM user_order
WHERE amount > (SELECT AVG(amount) FROM user_order);
```

执行下面的 SQL 语句，按集合范围使用嵌套子查询。

```sql
SELECT *
FROM user
WHERE id IN (SELECT DISTINCT user_id FROM user_order);
```

执行下面的 SQL 语句，

```sql
SELECT *
FROM user_order
WHERE amount > ANY (SELECT amount FROM user_order WHERE user_id = 3);
```
