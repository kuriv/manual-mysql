# 分库分表

分库分表是解决单数据库或单表数据量过大、并发过高的拆分方案。

| 拆分类型 |                       本质                       |
| :------: | :----------------------------------------------: |
| 垂直分库 | 按业务模块拆分数据库，每个数据库中的表结构不相同 |
| 水平分库 |  按数据规则拆分数据库，每个数据库中的表结构相同  |
| 垂直分表 |         按字段拆分表，每张表的字段不相同         |
| 水平分表 |        按记录行拆表，每张表的字段完全相同        |
