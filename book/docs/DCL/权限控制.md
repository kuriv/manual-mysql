# 权限控制

执行下面的 SQL 语句，查询指定用户的权限。

```sql
SHOW GRANTS FOR 'demo'@'localhost';
```

执行下面的 SQL 语句，为指定用户授予全局最高权限。

```sql
GRANT ALL PRIVILEGES ON *.* TO 'demo'@'localhost';
```

执行下面的 SQL 语句，为指定用户授予指定数据库的完整权限。

```sql
GRANT ALL PRIVILEGES ON demo.* TO 'demo'@'localhost';
```

执行下面的 SQL 语句，为指定用户授予指定数据库的只读权限。

```sql
GRANT SELECT ON demo.* TO 'demo'@'localhost';
```
