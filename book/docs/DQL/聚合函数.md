# 聚合函数

执行下面的 SQL 语句，统计全表中所有数据总量。

```sql
SELECT COUNT(*) AS total FROM user_login;
```

执行下面的 SQL 语句，统计全表中不为空的数据总量。

```sql
SELECT COUNT(id) AS total FROM user_login;
```

执行下面的 SQL 语句，查询全表中最大的主键 ID 。

```sql
SELECT MAX(id) AS max_id FROM user_login;
```

执行下面的 SQL 语句，查询全表中最小的主键 ID 。

```sql
SELECT MIN(id) AS min_id FROM user_login;
```

执行下面的 SQL 语句，查询全表中主键 ID 的平均值。

```sql
SELECT AVG(id) AS avg_id FROM user_login;
```

执行下面的 SQL 语句，查询全表中主键 ID 的总和。

```sql
SELECT SUM(id) AS sum_id FROM user_login;
```
