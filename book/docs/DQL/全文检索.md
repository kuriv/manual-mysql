# 全文检索

执行下面的 SQL 语句，使用自然语言模式匹配关键词。注意，若关键词的出现频率超过半数的记录行，则该关键词将会被停用。

```sql
SELECT *, MATCH(title, content) AGAINST('mysql' IN NATURAL LANGUAGE MODE) AS score
FROM article
WHERE MATCH(title, content) AGAINST('mysql' IN NATURAL LANGUAGE MODE);
```

执行下面的 SQL 语句，使用布尔模式进行精确短语匹配。

```sql
SELECT *
FROM article
WHERE MATCH(title, content) AGAINST('mysql' IN BOOLEAN MODE);
```

执行下面的 SQL 语句，使用布尔模式按照包含与未包含关系匹配关键词。

```sql
SELECT *
FROM article
WHERE MATCH(title, content) AGAINST('+mysql -docker' IN BOOLEAN MODE);
```

执行下面的 SQL 语句，使用布尔模式进行前缀匹配。

```sql
SELECT *
FROM article
WHERE MATCH(title, content) AGAINST('my*' IN BOOLEAN MODE);
```
