# 视图

执行下面的 SQL 语句，创建新的视图。

```sql
CREATE VIEW v_user AS
SELECT u.id, u.name AS username, d.name AS department
FROM user AS u
LEFT JOIN user_dept AS d ON u.dept_id = d.id;
```

执行下面的 SQL 语句，查询指定视图的结构。

```sql
DESC v_user;
```

执行下面的 SQL 语句，查询指定视图的创建语句。

```sql
SHOW CREATE VIEW v_user;
```

执行下面的 SQL 语句，查询指定视图中的所有数据。

```sql
SELECT * FROM v_user;
```

执行下面的 SQL 语句，修改指定的视图。

```sql
ALTER VIEW v_user AS SELECT id, name FROM user WHERE dept_id = 1;
```

执行下面的 SQL 语句，删除指定的视图。

```sql
DROP VIEW v_user;
```

执行下面的 SQL 语句，当视图存在时才执行删除操作。

```sql
DROP VIEW IF EXISTS v_user;
```

执行下面的 SQL 语句，强制校验数据满足当前视图的条件。

```sql
CREATE VIEW v1 AS SELECT id, name, dept_id FROM user WHERE dept_id = 1 WITH LOCAL CHECK OPTION;
```

执行下面的 SQL 语句，强制校验数据满足当前以及嵌套视图的条件。

```sql
CREATE VIEW v2 AS SELECT id, name, dept_id FROM v1 WHERE dept_id = 2 WITH CASCADED CHECK OPTION;
```
