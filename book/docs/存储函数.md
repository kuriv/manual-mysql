# 存储函数

执行下面的 SQL 语句，查询指定数据库中的所有存储函数。

```sql
SELECT *
FROM information_schema.ROUTINES
WHERE ROUTINE_SCHEMA = 'demo' AND ROUTINE_TYPE = 'FUNCTION';
```

执行下面的 SQL 语句，创建新的存储函数。

```sql
CREATE FUNCTION func()
RETURNS INT
DETERMINISTIC
BEGIN
    DECLARE num INT UNSIGNED DEFAULT 0;
    DECLARE sum INT UNSIGNED DEFAULT 0;
    SET num := 10;
    WHILE num > 0
        DO
            SET sum := sum + num;
            SET num := num - 1;
    END WHILE;
    RETURN sum;
END;
```

执行下面的 SQL 语句，调用指定的存储函数。

```sql
SELECT func();
```

执行下面的 SQL 语句，查询指定存储函数的创建语句。

```sql
SHOW CREATE FUNCTION func;
```

执行下面的 SQL 语句，删除指定的存储函数。

```sql
DROP FUNCTION func;
```

执行下面的 SQL 语句，当存储函数存在时才执行删除操作。

```sql
DROP FUNCTION IF EXISTS func;
```
