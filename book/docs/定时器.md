# 定时器

执行下面的 SQL 语句，查看所有的定时器。

```sql
SHOW EVENTS;
```

执行下面的 SQL 语句，查看定时器开启状态。

```sql
SELECT @@global.event_scheduler;
```

执行下面的 SQL 语句，临时开启定时器，可以在配置文件中进行设置。

```sql
SET @@global.event_scheduler = ON;
```

执行下面的 SQL 语句，创建一次性定时器。

```sql
CREATE EVENT demo
ON SCHEDULE AT NOW() + INTERVAL 1 MINUTE
DO
INSERT INTO event_log (message) VALUES ('EVENT ONCE');
```

执行下面的 SQL 语句，创建循环定时器。

```sql
CREATE EVENT demo
ON SCHEDULE EVERY 10 SECOND
STARTS NOW()
ENDS NOW() + INTERVAL 1 MINUTE
DO
INSERT INTO event_log (message) VALUES ('EVENT LOOP');
```

执行下面的 SQL 语句，启用指定的定时器。

```sql
ALTER EVENT demo ENABLE;
```

执行下面的 SQL 语句，禁用指定的定时器。

```sql
ALTER EVENT demo DISABLE;
```

执行下面的 SQL 语句，删除指定的定时器。

```sql
DROP EVENT demo;
```

执行下面的 SQL 语句，当定时器存在时才执行删除操作。

```sql
DROP EVENT IF EXISTS demo;
```
