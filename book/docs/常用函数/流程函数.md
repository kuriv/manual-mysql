# 流程函数

执行下面的 SQL 语句，使用单条件判断。

```sql
SELECT
    username,
    create_time,
    IF(DATEDIFF(NOW(), create_time) > 30, 'old', 'new') AS user_type
FROM user_login;
```

执行下面的 SQL 语句，使用空值判断。

```sql
SELECT
    username,
    create_time,
    IFNULL(create_time, 'unknown') AS register_time
FROM user_login;
```

执行下面的 SQL 语句，使用搜索型多分支判断。

```sql
SELECT
    id,
    username,
    CASE
        WHEN id <= 2 THEN 'foo'
        WHEN id <= 4 THEN 'bar'
        WHEN id <= 5 THEN 'baz'
        ELSE 'qux'
    END AS user_level
FROM user_login;
```

执行下面的 SQL 语句，使用等值匹配分支判断。

```sql
SELECT
    id,
    username,
    CASE id
        WHEN 1 THEN 'foo'
        WHEN 2 THEN 'bar'
        WHEN 3 THEN 'baz'
        ELSE 'qux'
    END AS user_level
FROM user_login;
```
