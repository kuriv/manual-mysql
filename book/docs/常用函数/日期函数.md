# 日期函数

执行下面的 SQL 语句，获取当前日期。

```sql
SELECT CURDATE();
```

执行下面的 SQL 语句，获取当前时间。

```sql
SELECT CURTIME();
```

执行下面的 SQL 语句，获取当前完整的日期与时间。

```sql
SELECT NOW();
```

执行下面的 SQL 语句，提取年份数值。

```sql
SELECT create_time, YEAR(create_time) AS year FROM user_login;
```

执行下面的 SQL 语句，提取月份数值。

```sql
SELECT create_time, MONTH(create_time) AS month FROM user_login;
```

执行下面的 SQL 语句，提取日期数值。

```sql
SELECT create_time, DAY(create_time) AS day FROM user_login;
```

执行下面的 SQL 语句，对指定日期进行时间偏移计算。

```sql
SELECT create_time, DATE_ADD(create_time, INTERVAL 7 DAY) AS after_7_days FROM user_login;
```

执行下面的 SQL 语句，计算两个日期之间相差的天数。

```sql
SELECT create_time, DATEDIFF(NOW(), create_time) AS registered_days FROM user_login;
```
