# 日志

执行下面的 SQL 语句，查看错误日志文件路径。

```sql
SELECT @@global.log_error;
```

执行下面的 SQL 语句，查看二进制日志文件路径。

```sql
SELECT @@global.log_bin_basename;
```

执行下面的命令，使用 MySQL 工具查看二进制日志。

```
mysqlbinlog --no-defaults -vv binlog.000001
```

执行下面的 SQL 语句，删除全部的二进制日志。

```sql
RESET MASTER;
```

执行下面的 SQL 语句，删除指定编号之前的二进制日志。

```sql
PURGE MASTER LOGS TO 'binlog.002100';
```

执行下面的 SQL 语句，查看查询日志开启状态。

```sql
SELECT @@global.general_log;
```

执行下面的 SQL 语句，查看查询日志文件路径。

```sql
SELECT @@global.general_log_file;
```
