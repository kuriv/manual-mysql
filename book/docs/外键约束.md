# 外键约束

执行下面的 SQL 语句，创建表并添加外键约束。

```sql
CREATE TABLE user (
    id INT UNSIGNED PRIMARY KEY AUTO_INCREMENT,
    name VARCHAR(50) NOT NULL UNIQUE,
    dept_id INT UNSIGNED,
    CONSTRAINT fk_user_dept FOREIGN KEY (dept_id) REFERENCES user_dept(id)
);
```

执行下面的 SQL 语句，为指定的表单独添加外键约束。

```sql
ALTER TABLE user ADD CONSTRAINT fk_user_dept FOREIGN KEY (dept_id) REFERENCES user_dept(id);
```

执行下面的 SQL 语句，删除指定表的外键约束。

```sql
ALTER TABLE user DROP FOREIGN KEY fk_user_dept;
```

执行下面的 SQL 语句，进一步添加级联操作，当从表存在关联数据时，禁止删除主表关联数据。

```sql
ALTER TABLE user
    ADD CONSTRAINT fk_user_dept FOREIGN KEY (dept_id) REFERENCES user_dept(id)
    ON DELETE RESTRICT
    ON UPDATE RESTRICT;
```

执行下面的 SQL 语句，进一步添加级联操作，当从表存在关联数据时，同步删除从表关联数据。

```sql
ALTER TABLE user
    ADD CONSTRAINT fk_user_dept FOREIGN KEY (dept_id) REFERENCES user_dept(id)
    ON DELETE CASCADE
    ON UPDATE CASCADE;
```

执行下面的 SQL 语句，进一步添加级联操作，当从表存在关联数据时，同步置空从表关联数据。

```sql
ALTER TABLE user
    ADD CONSTRAINT fk_user_dept FOREIGN KEY (dept_id) REFERENCES user_dept(id)
    ON DELETE SET NULL
    ON UPDATE SET NULL;
```
