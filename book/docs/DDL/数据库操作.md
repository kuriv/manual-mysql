# 数据库操作

执行下面的 SQL 语句，查询所有数据库。

```sql
SHOW DATABASES；
```

执行下面的 SQL 语句，查询当前选择的数据库。

```sql
SELECT DATABASE();
```

执行下面的 SQL 语句，创建新的数据库。

```sql
CREATE DATABASE demo;
```

执行下面的 SQL 语句，当数据库不存在时才执行创建操作。

```sql
CREATE DATABASE IF NOT EXISTS demo;
```

执行下面的 SQL 语句，创建新的数据库，同时指定默认字符集和排序规则。

```sql
CREATE DATABASE demo DEFAULT CHARACTER SET utf8mb4 DEFAULT COLLATE utf8mb4_general_ci;
```

执行下面的 SQL 语句，修改指定数据库的默认字符集和排序规则。

```sql
ALTER DATABASE demo DEFAULT CHARACTER SET utf8mb4 DEFAULT COLLATE utf8mb4_general_ci;
```

执行下面的 SQL 语句，删除指定的数据库。

```sql
DROP DATABASE demo;
```

执行下面的 SQL 语句，当数据库存在时才执行删除操作。

```sql
DROP DATABASE IF EXISTS demo;
```

执行下面的 SQL 语句，查看指定数据库的默认字符集和排序规则。

```sql
SHOW CREATE DATABASE demo;
```

执行下面的 SQL 语句，选择指定的数据库。

```sql
USE demo;
```
