# 表操作

执行下面的 SQL 语句，查询当前数据库中的所有表。

```sql
SHOW TABLES;
```

执行下面的 SQL 语句，创建新的表。

```sql
CREATE TABLE data_type_example (
    -- 整数类型
    col_tinyint TINYINT COMMENT 'TINYINT',
    col_smallint SMALLINT COMMENT 'SMALLINT',
    col_mediumint MEDIUMINT COMMENT 'MEDIUMINT',
    col_int INT COMMENT 'INT',
    col_bigint BIGINT COMMENT 'BIGINT',

    -- 小数类型
    col_float FLOAT COMMENT 'FLOAT',
    col_double DOUBLE COMMENT 'DOUBLE',
    
    -- 定点数类型
    col_decimal DECIMAL(10, 2) COMMENT 'DECIMAL',

    -- 字符串类型
    col_char CHAR(100) COMMENT 'CHAR',
    col_varchar VARCHAR(100) COMMENT 'VARCHAR',
    col_tinytext TINYTEXT COMMENT 'TINYTEXT',
    col_text TEXT COMMENT 'TEXT',
    col_mediumtext MEDIUMTEXT COMMENT 'MEDIUMTEXT',
    col_longtext LONGTEXT COMMENT 'LONGTEXT',

	-- 枚举类型
    col_enum ENUM('foo', 'bar') COMMENT 'ENUM',

    -- 集合类型
    col_set SET('foo', 'bar', 'baz') COMMENT 'SET',

    -- JSON 类型
    col_json JSON COMMENT 'JSON',

    -- 二进制类型
    col_tinyblob TINYBLOB COMMENT 'TINYBLOB',
    col_blob BLOB COMMENT 'BLOB',
    col_mediumblob MEDIUMBLOB COMMENT 'MEDIUMBLOB',
    col_longblob LONGBLOB COMMENT 'LONGBLOB',

    -- 日期时间类型
    col_year YEAR COMMENT 'YEAR',
    col_date DATE COMMENT 'DATE',
    col_time TIME COMMENT 'TIME',
    col_timestamp TIMESTAMP COMMENT 'TIMESTAMP',
    col_datetime DATETIME COMMENT 'DATETIME'
) COMMENT 'EXAMPLE';
```

执行下面的 SQL 语句，当表不存在时才执行创建操作。

```sql
CREATE TABLE IF NOT EXISTS demo (
    id INT UNSIGNED PRIMARY KEY AUTO_INCREMENT,
    username VARCHAR(20) NOT NULL UNIQUE,
    password VARCHAR(50) NOT NULL,
    create_time DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP
);
```

执行下面的 SQL 语句，为已有的表新增字段。

```sql
ALTER TABLE demo ADD login_time DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP;
```

执行下面的 SQL 语句，修改表中指定字段的数据类型。

```sql
ALTER TABLE demo MODIFY login_time TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP;
```

执行下面的 SQL 语句，修改表中指定字段的字段名与数据类型。

```sql
ALTER TABLE demo CHANGE login_time login_status TINYINT UNSIGNED NOT NULL DEFAULT 0;
```

执行下面的 SQL 语句，删除表中指定的字段。

```sql
ALTER TABLE demo DROP login_status;
```

执行下面的 SQL 语句，查询指定表的结构。

```sql
DESC demo;
```

执行下面的 SQL 语句，查询指定表的建表语句。

```sql
SHOW CREATE TABLE demo;
```

执行下面的 SQL 语句，修改指定的表名。

```sql
ALTER TABLE demo RENAME TO user_login;
```

执行下面的 SQL 语句，删除指定的表。

```sql
DROP TABLE user_login;
```

执行下面的 SQL 语句，当表存在时才执行删除操作。

```sql
DROP TABLE IF EXISTS user_login;
```

执行下面的 SQL 语句，删除指定的表，并重新创建该表。

```sql
TRUNCATE TABLE user_login;
```
