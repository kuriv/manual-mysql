# 触发器

执行下面的 SQL 语句，查看所有的触发器。

```sql
SHOW TRIGGERS;
```

执行下面的 SQL 语句，在插入数据之前自动执行相关的 SQL 语句。

```sql
CREATE TRIGGER tri_user_before_insert
BEFORE INSERT
ON user
FOR EACH ROW
BEGIN
    INSERT INTO user_log (action) VALUES ('BEFORE INSERT');
END;
```

执行下面的 SQL 语句，在插入数据之后自动执行相关的 SQL 语句。

```sql
CREATE TRIGGER tri_user_after_insert
AFTER INSERT
ON user
FOR EACH ROW
BEGIN
    INSERT INTO user_log (action) VALUES (CONCAT('AFTER INSERT ', NEW.id));
END;
```

执行下面的 SQL 语句，在更新数据之前自动执行相关的 SQL 语句。

```sql
CREATE TRIGGER tri_user_before_update
BEFORE UPDATE
ON user
FOR EACH ROW
BEGIN
    INSERT INTO user_log (action) VALUES (CONCAT('BEFORE UPDATE ', OLD.name, ' -> ', NEW.name));
END;
```

执行下面的 SQL 语句，在更新数据之后自动执行相关 SQL 语句。

```sql
CREATE TRIGGER tri_user_after_update
AFTER UPDATE
ON user
FOR EACH ROW
BEGIN
    INSERT INTO user_log (action) VALUES (CONCAT('AFTER UPDATE ', OLD.name, ' -> ', NEW.name));

```

执行下面的 SQL 语句，在删除数据之前自动执行相关 SQL 语句。

```sql
CREATE TRIGGER tri_user_before_delete
BEFORE DELETE
ON user
FOR EACH ROW
BEGIN
    INSERT INTO user_log (action) VALUES (CONCAT('BEFORE DELETE ', OLD.id));
END;
```

执行下面的 SQL 语句，在删除数据之后自动执行相关 SQL 语句。

```sql
CREATE TRIGGER tri_user_after_delete

ON user

```

执行下面的 SQL 语句，删除指定的触发器。

```sql
DROP TRIGGER tri_user_before_insert;
```

执行下面的 SQL 语句，当触发器存在时才执行删除操作。

```sql
DROP TRIGGER IF EXISTS tri_user_before_insert;
```
