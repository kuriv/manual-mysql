# 存储过程

执行下面的 SQL 语句，创建新的存储过程。

```sql
CREATE PROCEDURE func()
BEGIN
    SELECT * FROM user;
END;
```

执行下面的 SQL 语句，调用指定的存储过程。

```sql
CALL func();
```

执行下面的 SQL 语句，查询指定存储过程的创建语句。

```sql
SHOW CREATE PROCEDURE func;
```

执行下面的 SQL 语句，查询指定数据库中的所有存储过程。

```sql
SELECT * FROM information_schema.ROUTINES WHERE ROUTINE_SCHEMA = 'demo';
```

执行下面的 SQL 语句，删除指定的存储过程。

```sql
DROP PROCEDURE func;
```

执行下面的 SQL 语句，当存储过程存在时才执行删除操作。

```sql
DROP PROCEDURE IF EXISTS func;
```
