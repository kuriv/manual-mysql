# 存储过程

执行下面的 SQL 语句，创建新的存储过程。

```sql
CREATE PROCEDURE func()
BEGIN
    SELECT * FROM user;
END;
```

执行下面的 SQL 语句，调用指定的存储过程。

```sql
CALL func();
```

执行下面的 SQL 语句，查询指定存储过程的创建语句。

```sql
SHOW CREATE PROCEDURE func;
```

执行下面的 SQL 语句，查询指定数据库中的所有存储过程。

```sql
SELECT * FROM information_schema.ROUTINES WHERE ROUTINE_SCHEMA = 'demo';
```

执行下面的 SQL 语句，删除指定的存储过程。

```sql
DROP PROCEDURE func;
```

执行下面的 SQL 语句，当存储过程存在时才执行删除操作。

```sql
DROP PROCEDURE IF EXISTS func;
```

执行下面的 SQL 语句，在存储过程中使用局部变量。

```sql
CREATE PROCEDURE func()
BEGIN
    DECLARE count INT UNSIGNED DEFAULT 0;
    SELECT COUNT(*) INTO count FROM user;
    SELECT count;
END;
```

执行下面的 SQL 语句，在存储过程中使用条件判断。

```sql
CREATE PROCEDURE func()
BEGIN
    DECLARE score INT UNSIGNED DEFAULT 0;
    DECLARE result VARCHAR(10);
    SET score := 90;
    IF score >= 90 THEN
        SET result := 'Excellent';
    ELSEIF score >= 60 THEN
        SET result := 'Pass';
    ELSE
        SET result := 'Fail';
    END IF;
    SELECT result;
END;
```

执行下面的 SQL 语句，在存储过程中使用分支判断。

```sql
CREATE PROCEDURE func()
BEGIN
    DECLARE score INT UNSIGNED DEFAULT 0;
    DECLARE result VARCHAR(10);
    SET score := 90;
    CASE
        WHEN score >= 90 THEN
            SET result := 'Excellent';
        WHEN score >= 60 THEN
            SET result := 'Pass';
        ELSE
            SET result := 'Fail';
    END CASE;
    SELECT result;
END;
```

执行下面的 SQL 语句，在存储过程中使用循环控制。

```sql
CREATE PROCEDURE func()
BEGIN
    DECLARE num INT UNSIGNED DEFAULT 0;
    DECLARE sum INT UNSIGNED DEFAULT 0;
    SET num := 10;
    WHILE num > 0 DO
        SET sum := sum + num;
        SET num := num - 1;
    END WHILE;
    SELECT sum;
END;
```

执行下面的 SQL 语句，在存储过程中使用另一种循环控制。

```sql
CREATE PROCEDURE func()
BEGIN
    DECLARE num INT UNSIGNED DEFAULT 0;
    DECLARE sum INT UNSIGNED DEFAULT 0;
    SET num := 10;
    REPEAT
        SET sum := sum + num;
        SET num := num - 1;
    UNTIL num <= 0
    END REPEAT;
    SELECT sum;
END;
```

执行下面的 SQL 语句，在存储过程中分别使用输入参数和输出参数。

```sql
CREATE PROCEDURE func(IN score INT, OUT result VARCHAR(10))
BEGIN
    IF score >= 90 THEN
        SET result := 'Excellent';
    ELSEIF score >= 60 THEN
        SET result := 'Pass';
    ELSE
        SET result := 'Fail';
    END IF;
END;

SET @result = '';
CALL func(88, @result);
SELECT @result;
```

执行下面的 SQL 语句，在存储过程中使用输入输出参数。

```sql
CREATE PROCEDURE func(INOUT num INT)
BEGIN
    SET num := num * num;
END;

SET @num = 10;
CALL func(@num);
SELECT @num;
```
